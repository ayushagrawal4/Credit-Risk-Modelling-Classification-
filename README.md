# Credit-Risk-Modelling-Classification-

Built a credit risk classification model to minimize loan defaults using XGBoost and Logistic Regression. Applied SMOTE for class imbalance and deployed a real-time prediction tool via Streamlit. Achieved 94% accuracy and 96% recall.

Objective: Built a classification model to assess credit risk and identify high-risk loan applicants, helping reduce default rates and support better lending decisions.

Data & Modeling: Preprocessed credit data with scaling and encoding techniques. Trained Logistic Regression and XGBoost models, incorporating SMOTE to address class imbalance for fairer predictions.

Evaluation: Focused on recall, precision, and accuracy as key metrics. Logistic Regression achieved 94% accuracy and 96% recall, outperforming other models in capturing high-risk cases.

Deployment: Deployed the model using Streamlit, enabling real-time credit risk forecasting through an interactive, stakeholder-friendly web interface.
